# CarePulse — Smart Elderly Care & Medication Management Ecosystem

Built for **PromptWars x Catalyst Hackathon (15 Nov 2026)**.

## Problem Statement
Elderly individuals often struggle with managing multiple daily medications and doctor appointments independently, while caretakers lack real-time visibility into missed doses.

## Key Features
- **Passcode-Protected Shared Ecosystem:** Secure role-based access (`Elderly View` with high-readability text & `Family/Caretaker View` for full schedule management). Demo Passcode: `1234`.
- **Smart Medication Management:** Add, edit, delete, and track daily medication adherence with real-time percentage scoring.
- **Proactive Email Reminder System:** Automated alert logging and one-click proactive email dispatch (`mailto` integration) for missed/upcoming doses and doctor appointments.
- **Accessibility & Safety First:** Built-in Text-to-Speech voice reminder reader (`Web Speech API`), Health Vitals logger, and one-tap Emergency SOS alert.

## Tech Stack
- HTML5, Tailwind CSS, Vanilla JavaScript (ES6+), Web Speech API, LocalStorage Persistence.
